# 乒乓球计分系统使用说明

## 一、程序组成

| 程序 | 文件 | 用途 |
|------|------|------|
| 单项计分 | `PingPang_IndividualEvents_for_joystick_V95_20260814.py` | 两名选手的单打比赛计分 |
| 团体计分 | `PingPang_TeamEvents_for_joystick_V95_20260806.py` | 两支队伍（男单/男双等）团体赛计分 |
| 手柄配置 | `Joystick_for_PingPang.py` | 为上面两个程序统一配置手柄按键 |

两个计分程序均支持**键盘快捷键**和**Xbox游戏手柄**（推荐模式）操作，运行后自动全屏黑底白字。

## 二、运行环境

- Windows 系统
- Python 已安装依赖：`pip install PySide6 pygame`
- 直接运行对应 `.py` 文件，或者运行相应的打包 exe 文件

## 三、操作说明（键盘快捷键）

两个计分程序快捷键一致：

| 快捷键 | 功能 |
|--------|------|
| `W` / `S` | 左侧 加分 / 减分 |
| `O` / `L` | 右侧 加分 / 减分 |
| `B` | 本局结束（结算本局胜负、保存并清零小分） |
| `N` | 交换场地（队伍/选手/大小比分整体互换） |
| `V` | 打开设置（单项设选手姓名；团体设赛制、类型、队伍及选手） |
| `M` | 查看比赛结果（全屏展示） |
| `Esc` / `Ctrl+C` | 退出程序 |

> 界面上的按钮均标注了对应快捷键（如「加分\<w\>」），也可用鼠标点击。

## 四、Xbox手柄按键配置（可选）

1. 插入手柄后运行 `Joystick_for_PingPang.py`（未检测到手柄会提示并退出）。
2. 点击某项功能的「配置」按钮，再按手柄上的对应按键（按钮或方向键上/下），即完成绑定。
3. 点击「保存」，配置会**同时写入** `Config_IndividualEvents.json` 和 `Config_TeamEvents.json`（不影响两文件中的其他字段）。
4. 「恢复默认」可一键还原默认键位。

**默认键位**（Xbox 布局，按钮编号 0=A、1=B、2=X、3=Y）：

| 功能 | 默认按键 |
|------|----------|
| 左侧加分 | 方向键 上 |
| 左侧减分 | 方向键 下 |
| 右侧加分 | 按钮 Y |
| 右侧减分 | 按钮 A |
| 本局结束 | 按钮 B |
| 交换场地 | 按钮 X |

若两个功能绑定了同一按键，保存时会提示「按键重复」并拒绝保存。

## 五、GameSir-N2 Lite 手柄连接指南（仅供参考）

本程序不是商业软件，本人开发过程中仅使用了二款手柄，一款是君盈Xbox游戏手柄（已经不再销售），一款是GameSir-N2 Lite游戏手柄。

君盈Xbox游戏手柄使用USB接口的2.4G接收器连接到windows上，非常稳定，几乎没有出过差错。所以强烈推荐大家使用这种连接方式的手柄。

GameSir-N2 Lite游戏手柄很强大，有很多模式。通过蓝牙和windows连接。注意只有windows识别为Xbox wireless controller时，程序才能正确使用手柄。

其他手柄需要大家去测试，欢迎反馈问题给我。jiangheng010@qq.com

本程序使用 **pygame / SDL** 层来检测手柄，因此手柄必须被 Windows 正确识别为 **Xbox 兼容控制器**才能被程序发现。以下是 GameSir-N2 Lite（启明星2）的详细连接方法和常见问题处理。

### 连接模式说明

GameSir-N2 Lite 支持多种平台连接模式，不同模式下手柄的行为完全不同：

| 组合键 | 模式 | Home 灯 | Windows 蓝牙名 | 程序能否识别 |
|--------|------|---------|----------------|--------------|
| A + Home | Switch 模式 | 红灯 | — | ❌ 不能 |
| B + Home | **Xbox 模式（推荐）** | 蓝灯 | **Xbox Wireless Controller** | ✅ 能 |
| X + Home | 2.4G 接收器模式 | 绿灯 | — | ✅ 能（需另购接收器） |

> ⚠️ **默认开机回到上一次使用的模式**。如果手柄之前连过手机/平板/Switch，它开机后仍会停留在那个模式，Windows 虽然能在蓝牙列表里看到它，但 pygame/SDL 看不到这个手柄。

### 蓝牙连接（推荐）

**第一步：清除 Windows 中旧的配对记录**

打开「设置 → 蓝牙和其他设备」，如果列表里有 `GameSir-Nova 2 Lite_G`、`GameSir Wireless Controller` 或任何旧的手柄条目，**逐个删除设备**。

**第二步：手柄进入 Xbox 模式**

手柄关机后（长按 Home 键 5 秒直到灯灭），**同时长按 B + Home 键**，直到 Home 键蓝灯闪烁，松手。

**第三步：强制进入配对状态（重要）**

进入 Xbox 模式后，Home 蓝灯会 **慢闪（约 2 秒 1 次）**，这是「回连状态」，Windows 搜不到。需要手动强制进入「配对状态」：

> **同时长按 Home 键 + 截图键（Share 键）3 秒**，直到蓝灯 **快闪（每秒 2-3 次）**，此时 Windows 才能搜到。

**第四步：Windows 配对**

在蓝灯快闪期间（约 30-60 秒），立即在 Windows「设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙」中搜索，应能看到 **"Xbox Wireless Controller"**（不是 GameSir 开头的名字），点击自动配对。Home 灯**常亮**表示连接成功。

**配对失败？** 如果 Windows 搜不到或配对后 Home 灯仍慢闪：
1. 删设备后重新来一遍
2. 检查蓝牙是否为 5.0 模块（说明书要求）
3. 长按 Home + 截图键再次强制配对


### 常见问题

#### Q：Windows 蓝牙显示「已连接」，但程序提示「未检测到游戏手柄」

这是最常见的情况，原因几乎总是**手柄处在了非 Xbox 的连接模式**（比如安卓/iOS 模式）。诊断方法：
- 在 Windows 蓝牙列表中看设备名：如果显示 `GameSir-Nova 2 Lite_G` 或类似 GameSir 开头的名字，说明不在 Xbox 模式
- 正确的 Xbox 模式下，设备名应为 **"Xbox Wireless Controller"**
- 按「蓝牙连接」的步骤重新切换模式并配对

#### Q：蓝灯慢闪和快闪有什么区别？

| 闪速 | 含义 | 能否被新设备搜到 |
|------|------|------------------|
| **快闪**（每秒 2-3 次） | 配对状态 | ✅ 能 |
| **慢闪**（约 2 秒 1 次） | 回连状态，只找旧设备 | ❌ 不能 |

从慢闪切换到快闪，需要 **长按 Home + 截图键 3 秒**。

#### Q：旧配对记录删不干净怎么办？

打开「控制面板 → 设备和打印机」，在设备列表里右键旧的 GameSir / Xbox 手柄设备 → 删除设备。

## 六、团体赛特别说明

- **赛制**：`五场三胜制`（可设每场局数：三局二胜/五局三胜/七局四胜）或 `十五局八胜制`。
- **比赛类型**：男单、男双、女单、女双、混双。
- 赛制信息**必须在比赛开始前（所有比分均为 0 时）设置**，进行中不可修改。
- 换队伍或换选手时程序会自动结算上一场，请按弹窗提示确认。

## 七、数据文件

- 每局/每场比分自动保存为 `Score_IndividualEvents_*.txt` 或 `Score_TeamEvents_*.txt`（按日期时间命名），位于程序所在目录。
- 在「比赛结果」窗口中点「历史数据」或按 `H`，可浏览、加载历史计分文件。
